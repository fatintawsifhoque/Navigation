#  Navigation 

A side-by-side exploration of **client-side routing** built with both **React** and **Vue** — because the best way to learn is to compare.

---

##  What Is This?

Ever visited a website and wondered, *"Which page am I on right now?"* — good navigation tells you instantly. This project does exactly that, **twice** — once in React, once in Vue.

It's a small three-page app with a navigation bar that highlights the current page in **blue and bold**, so users never feel lost. The same concept, two different frameworks.

---

##  Why Two Versions?

Because understanding *how* something works is good — but understanding *how it works differently* across tools is **great**.

This project lets you:
- See how React and Vue solve the **same problem** differently
- Compare syntax, structure, and philosophy
- Decide which framework feels more natural to you
- Build a stronger foundation in modern frontend development
