# Navigation

A clean, minimal navigation app built with **React 18** and **React Router DOM v6** — where the active page link lights up so you always know where you are. Simple, but built with care.

---

##  What Is This?

Ever visited a website and wondered, *"Which page am I on right now?"* — good navigation tells you instantly. That's exactly what this project does.

It's a small three-page app with a navigation bar that highlights the current page in **blue and bold**, so users never feel lost.
